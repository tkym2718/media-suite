# 画像仕分けツール (Image Sorter)

ローカルの画像フォルダをブラウザ上で視覚的に確認しながら、タグごとにフォルダ分けできるツールです。
「ネオブルータリズム」をテーマにしたモダンで使いやすいUI（Bento Gridレイアウト）を採用しています。

## 主な機能

- **更新日時順のソート**: 指定したフォルダ内の画像を「新しい順」に自動で並べて表示します。
- **タグによる仕分け**: 各画像にタグを設定できます。「新規タグ」を作成すると、元のフォルダの中に自動でそのタグ名のサブフォルダが作成されます。
- **ファイル自動リネーム**: 仕分けた画像は移動先のフォルダ内で `タグ名_{連番}.拡張子` の形式に自動でリネームされます。
- **一括保存機能**: 複数の画像に対してタグを選んだ後、画面右上の「一括保存」ボタンを押すことでまとめて移動・整理が可能です。
- **ライトボックス（拡大表示）**: 画像のサムネイルをクリックすると、画面いっぱいに拡大表示して細部を確認できます。

## 必須環境

- **Node.js** (v14以上推奨)

## 使い方

### ツールの起動
プロジェクトフォルダの中にある **`start.bat`** をダブルクリックして実行してください。

- 初回起動時は、自動的に必要なファイル（パッケージ）がインストールされます（少し時間がかかります）。
- サーバーが起動すると、**自動的にブラウザが立ち上がり**ツール画面が表示されます。
- ※ ツールを使用している間は、黒い画面（コマンドプロンプト）は**閉じない**でください。使い終わったら閉じて構いません。

手動で起動する場合は、コマンドプロンプトで `npm install` を行った後、`npm start` を実行し、ブラウザで `http://localhost:3000` にアクセスしてください。

### 仕分けの手順
1. 画面右上の **「フォルダを選択」** ドロップダウンから、仕分けたい画像が入っているフォルダを選びます。
   *(※ 注意: このツールと同じディレクトリ、もしくはそのサブディレクトリにあるフォルダのみ選択可能です)*
2. 画像の一覧が表示されたら、各画像の左下にある **「タグを選択」** からタグを選びます。
3. 新しいタグを作りたい場合は **「＋ 新規タグ」** を選び、好きな名前を入力します。
4. 一つの画像をすぐに移動させたい場合は、タグの右側にある **矢印ボタン（移動ボタン）** を押します。
5. 複数の画像をまとめて移動させたい場合は、それぞれの画像でタグを選んだ後、画面右上にある **「一括保存」** ボタンを押します。
6. 全ての画像が画面からなくなれば仕分け完了です！

## ファイル構成

```text
仕分けツール/
├── server.js          # Node.js サーバー（バックエンドAPI・ファイル操作担当）
├── package.json       # プロジェクト設定と依存関係
├── README.md          # この説明書
└── public/            # ブラウザに表示されるフロントエンドファイル群
    ├── index.html     # メインのHTML
    ├── style.css      # スタイルシート（ネオブルータリズムUI）
    └── app.js         # クライアント側のJavaScript（UI制御・一括保存ロジック）
```

## トラブルシューティング

- **フォルダが選択肢に出ない**: 
  対象のフォルダは `server.js` と同じディレクトリに置いてください。
- **画像が表示されない**: 
  対応している拡張子は `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.bmp` です。
- **サーバーが起動しない**: 
  すでに他のアプリがポート `3000` 番を使っている可能性があります。その場合は `server.js` 内の `PORT = 3000;` を `3001` 等に変更して再起動してください。
