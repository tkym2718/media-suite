# Media Suite

`video-viewer` / `image-viewer` / `Music-Player` を 1 つに統合した Electron デスクトップアプリです。
起動時にランチャー画面で使用する機能（Music / Video / Image）を選択します。UI は Music-Player のデザイン言語（React + Tailwind）に統一しています。

ネイティブの **FFmpeg / FFprobe / yt-dlp** を Electron のメインプロセス（Node.js）から呼び出すことで、
ブラウザでは難しかった「クリップの新規エンコード」「動画ダウンロード」を実現しています。

## 必要環境

- Node.js 18 以降
- FFmpeg / FFprobe（クリップ書き出し・メタデータ・サムネイルに使用）
- yt-dlp（動画ダウンロードに使用 / 任意）

`ffmpeg` / `ffprobe` / `yt-dlp` が PATH に通っていれば自動検出します。
見つからない場合はランチャー画面下部の各バッジをクリックして実行ファイルを手動指定できます（設定は保存されます）。

## セットアップ

```bash
cd media-suite
npm install
```

## 開発実行

```bash
npm run dev
```

Vite 開発サーバ（`http://127.0.0.1:5173`）が立ち上がり、その後 Electron ウィンドウが開きます。

## ビルド / 配布

```bash
npm run build      # 型チェック + Vite ビルド（dist/ を生成）
npm start          # ビルド済みアプリを Electron で起動
npm run dist       # electron-builder でインストーラを作成（任意）
```

## アーキテクチャ

```
media-suite/
├─ electron/
│  ├─ main.cjs       # メインプロセス: ウィンドウ / media:// プロトコル / IPC(ffmpeg, ffprobe, yt-dlp)
│  └─ preload.cjs    # contextBridge で window.api を公開
├─ src/
│  ├─ App.tsx        # 機能切り替え（home/music/video/image）
│  ├─ features/
│  │  ├─ Launcher.tsx          # ランチャー（機能選択 + ツール状態）
│  │  ├─ music/MusicPlayer.tsx # 音楽プレイヤー + クリップ
│  │  ├─ video/VideoViewer.tsx # 動画ビューア + クリップ + ダウンロード
│  │  └─ image/ImageViewer.tsx # 画像ビューア
│  ├─ components/    # TopBar / Toggle / ClipPanel / ToolStatusBar 等の共通UI
│  └─ lib/           # format / useTools 等
```

- ローカルファイルは `media://m/<encoded-path>` というカスタムプロトコル経由で安全に読み込みます（`webSecurity` を無効化しません）。
- FFmpeg/yt-dlp は絶対パスのファイルに対して直接処理するため、ブラウザの Blob 制約を受けません。

## 機能

### 共通

- 起動時のランチャーで機能を選択。各画面左上の戻るボタンでランチャーへ戻ります。
- 外部ツール（FFmpeg/FFprobe/yt-dlp）の検出状態を表示。未検出ならクリックで実行ファイルを指定。

### Music Player

- フォルダ / 複数ファイル読み込み、ドラッグ&ドロップで並べ替え、リピート（none/all/one）。
- FFprobe でタイトル/アーティスト/アルバム/長さを取得、現在曲のカバーアートを FFmpeg で抽出。
- **クリップモード（トグル）**: ON にすると通常の再生ボタン等を隠し、クリップ専用 UI を表示。
  - シークバーで位置を合わせ、開始(IN)/終了(OUT)を「ここに設定」。±0.1s / ±1s で微調整。
  - 開始 < 終了になるとクリップボタンが有効化。押すと **新規ファイルとして音声をエンコード**します（出力: 正確=再エンコード / 高速=ストリームコピー）。
  - クリップモード中でも Space キーで再生/一時停止が可能。

### Video Viewer

- フォルダ / 複数ファイル読み込み、前後移動、自動連続再生。
- シークプレビュー（サムネイル）、音量、再生速度、フルスクリーン、キーボードショートカット。
- 音声ラウドネス解析による「見どころ」ハイライト（シーク操作中に表示）。
- **ホイールのクールタイム**: 動画読み込み中はホイール送りを無視し、さらに `700ms` のクールタイムを設けて、高速切り替えによる読み込みエラーを防止します。
- **クリップモード**: Music Player と同じ IN/OUT 指定でクリップを書き出します（type=video, libx264+aac で再エンコード or コピー）。
- **yt-dlp ダウンロード**: URL を貼り付けて動画(mp4)/音声のみ(mp3/m4a/flac/wav)を保存。進捗バー・ログ表示・キャンセル対応。検出済みの FFmpeg を `--ffmpeg-location` に渡してマージ/抽出します。

ショートカット: `Space` 再生/一時停止、`←/→` 10秒、`↑/↓` 音量、`M` ミュート、`F` 全画面、`N/P` 次/前。

### Image Viewer

- フォルダ読み込み（サブフォルダ含む）、1ページ最大3枚表示。
- フォルダごとにグループ化し、各フォルダ内は更新日時の新しい順、サブフォルダは最新ファイル順に並べ替え。
- 前後移動（ボタン/ホイール/←→キー）、番号ジャンプ、スライドショー（1〜10秒）。

## 追加で実装した便利機能・提案

実装済み:

- ランチャーでの機能選択とツール状態の可視化 + 手動パス設定の永続化。
- クリップの「コピー(高速) / エンコード(正確)」切り替え、IN/OUT の微調整ボタンとプレビュー移動。
- yt-dlp の進捗/ログ/キャンセル、音声のみ抽出の形式選択。

今後の拡張候補（ご要望あれば対応します）:

- 動画のサムネイル一覧（グリッド）からの選択、連続クリップのキュー化・一括書き出し。
- クリップ範囲をシークバー上に視覚表示（IN/OUT ハンドルのドラッグ）。
- GIF / アニメ WebP 書き出し、フレーム単位のステップ送り（`,` / `.`）。
- 画像ビューアのズーム/パン、EXIF 表示、サムネイルストリップ。
- プレイリスト/お気に入りの保存、最近開いたフォルダ履歴。
- ライト/ダークテーマの手動切り替え。

## 既存アプリとの関係

`video-viewer` / `image-viewer` / `Music-Player` の各フォルダはそのまま残しています。
本アプリの動作に満足したら、それらは削除して問題ありません。
