# Clipforge

ローカルに保存した音楽・動画・画像を、ひとつのデスクトップアプリで扱える **Electron アプリ**です。
起動するとランチャー画面が表示され、使いたい機能を選んでから作業を始められます。

このリポジトリは、もともと別々に作っていた 3 つのツールを統合したものです。
初めて読む方向けに、それぞれが「何をするアプリか」を先に説明します。

---

## このアプリに含まれる機能

### Music Player（音楽プレイヤー）

**ローカルの音楽ファイルを聴くためのプレイヤー**です。

- フォルダや複数ファイルをまとめて読み込み、プレイリストとして再生できます
- 曲の並べ替え（ドラッグ&ドロップ）、リピート再生に対応
- 曲情報（タイトル・アーティスト・カバーアートなど）を自動取得して表示
- **クリップ書き出し**: 曲の一部だけを切り出して、新しい音声ファイルとして保存できます（配信素材や着信音の作成などに便利）

### Video Viewer（動画ビューア）

**ローカルの動画ファイルを再生・編集するためのビューア**です。

- フォルダ内の動画を連続再生、シークプレビュー、音量・再生速度の調整、フルスクリーン表示
- キーボードショートカット（Space で再生/一時停止、矢印キーでシーク・音量など）
- 音声のラウドネスを解析し、盛り上がりそうな「見どころ」位置をヒント表示
- **クリップ書き出し**: 動画の一部分だけを切り出して新しいファイルとして保存
- **動画ダウンロード**: URL を貼り付けて、YouTube などの動画・音声をローカルに保存（yt-dlp を使用）

### Image Viewer（画像ビューア）

**ローカルの画像フォルダを閲覧するためのビューア**です。

- フォルダ（サブフォルダ含む）を読み込み、画像をページ単位で表示（1 ページ最大 3 枚）
- フォルダごとにグループ化し、更新日時の新しい順に並べ替え
- 前後移動（ボタン・マウスホイール・キーボード）、番号ジャンプ、スライドショー（1〜10 秒間隔）

### 仕分け（Sorter）

**画像・動画・音声ファイルにタグを付けて整理するツール**です（ランチャーから起動）。

- 複数タグの付与、AND/OR による絞り込み
- タグに応じたフォルダ分け・一括整理

---

## なぜ Electron なのか

ブラウザだけのアプリでは難しい処理を、ネイティブの **FFmpeg / FFprobe / yt-dlp** をメインプロセスから呼び出すことで実現しています。

- クリップの新規エンコード（音声・動画の切り出し保存）
- 動画のメタデータ取得・サムネイル生成
- Web 上の動画・音声のダウンロード

ローカルファイルは `media://` というカスタムプロトコル経由で安全に読み込みます（`webSecurity` を無効化していません）。

---

## 必要環境

- Node.js 18 以降
- FFmpeg / FFprobe（クリップ書き出し・メタデータ・サムネイルに使用）
- yt-dlp（動画ダウンロードに使用 / 任意）

`ffmpeg` / `ffprobe` / `yt-dlp` が PATH に通っていれば自動検出します。
見つからない場合は、ランチャー画面下部の各バッジをクリックして実行ファイルを手動指定できます（設定は保存されます）。

## セットアップ

```bash
git clone <リポジトリURL>
cd media-suite
npm install
```

## 開発実行

```bash
npm run dev
```

Vite 開発サーバ（`http://127.0.0.1:5173`）が立ち上がり、その後 Electron ウィンドウが開きます。

## ビルド / 配布

```bash
npm run build      # 型チェック + Vite ビルド（dist/ を生成）
npm start          # ビルド済みアプリを Electron で起動
npm run dist       # electron-builder でインストーラを作成（任意）
```

## 各機能の詳細

### 共通

- 起動時のランチャーで機能を選択。各画面左上の戻るボタンでランチャーへ戻れます
- 外部ツール（FFmpeg / FFprobe / yt-dlp）の検出状態を表示。未検出ならクリックで実行ファイルを指定

### Music Player

- フォルダ / 複数ファイル読み込み、ドラッグ&ドロップで並べ替え、リピート（none / all / one）
- FFprobe でタイトル・アーティスト・アルバム・長さを取得、現在曲のカバーアートを FFmpeg で抽出
- **クリップモード（トグル）**: ON にするとクリップ専用 UI を表示
  - シークバーで位置を合わせ、開始 (IN) / 終了 (OUT) を「ここに設定」。±0.1s / ±1s で微調整
  - 開始 < 終了になるとクリップボタンが有効化。押すと **新規ファイルとして音声をエンコード**（出力: 正確=再エンコード / 高速=ストリームコピー）
  - クリップモード中でも Space キーで再生/一時停止が可能

### Video Viewer

- フォルダ / 複数ファイル読み込み、前後移動、自動連続再生
- シークプレビュー（サムネイル）、音量、再生速度、フルスクリーン、キーボードショートカット
- 音声ラウドネス解析による「見どころ」ハイライト（シーク操作中に表示）
- 動画読み込み中はホイール送りを無視し、さらに `700ms` のクールタイムを設けて高速切り替えによる読み込みエラーを防止
- **クリップモード**: Music Player と同じ IN/OUT 指定でクリップを書き出し（type=video, libx264+aac で再エンコード or コピー）
- **yt-dlp ダウンロード**: URL を貼り付けて動画 (mp4) / 音声のみ (mp3/m4a/flac/wav) を保存。進捗バー・ログ表示・キャンセル対応

ショートカット: `Space` 再生/一時停止、`←/→` 10秒、`↑/↓` 音量、`M` ミュート、`F` 全画面、`N/P` 次/前

### Image Viewer

- フォルダ読み込み（サブフォルダ含む）、1 ページ最大 3 枚表示
- フォルダごとにグループ化し、各フォルダ内は更新日時の新しい順、サブフォルダは最新ファイル順に並べ替え
- 前後移動（ボタン / ホイール / ←→ キー）、番号ジャンプ、スライドショー（1〜10 秒）

## 元になった個別ツールについて

このアプリは、以前それぞれ独立していた次の 3 ツールを 1 つにまとめたものです。

| 元のツール名 | 現在のアプリ内での名前 | 主な用途 |
|---|---|---|
| `Music-Player` | Music Player | ローカル音楽の再生・プレイリスト・音声クリップ |
| `video-viewer` | Video Viewer | ローカル動画の再生・クリップ・ダウンロード |
| `image-viewer` | Image Viewer | ローカル画像フォルダの閲覧・スライドショー |

リポジトリ内に元のフォルダが残っている場合がありますが、統合版の動作に問題がなければ削除して構いません。
